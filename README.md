# Character Sheet by KK

### What is it?

This is a single page application (in both senses) for the TTRPG Dungeons & Dragons that displays a character sheet, where you can enter/choose your character's info, and it will populate the sheet with the data derived from the input.

### Why is it?

It is always a hassle to create a character with all the details coming from different places, so this is an attempt to automate this process.

### What is it _not_?

This is not intended to use during playing the game. It's purpose is the initial creation of the character at the specified level.
